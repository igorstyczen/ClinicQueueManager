# MediQueue (ClinicQueueManager)

Desktopowa aplikacja WPF do zarządzania przychodnią: pacjenci, lekarze, wizyty, dashboard recepcji, triage i inteligentny czas wizyty.

**Autor:** Igor Styczeń

**Dokumentacja:** [dokumentacja.md](dokumentacja.md) (zrzuty ekranu w folderze `screenshots/`)

## Szybki start

```powershell
dotnet restore
dotnet build
dotnet run
```

**Wymagania:** Windows 10/11, .NET SDK 8.0

## Technologie

- C# / .NET 8 / WPF
- Entity Framework Core 9 + SQLite
